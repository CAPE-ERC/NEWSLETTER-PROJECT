CAPE Newsletter Automation

Public, static viewer for the bulletin's section agents — browse extracted edition data, build each agent's exact prompt, and review its output.

This page makes no API calls. It's a static site with no backend, so it can't call Anthropic on your behalf. Pick an edition and section below, review/edit the structured data, then Build prompt and copy it into claude.ai (or run the local dashboard with your own ANTHROPIC_API_KEY) to actually generate the draft. Paste the result back into the output box to keep it next to the data while you review — it stays in your browser only.
